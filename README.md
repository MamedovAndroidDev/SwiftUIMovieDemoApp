
This repository contains the SwiftUI Movie Demo application. 

## 📂 Project Structure & Configurations

The configuration and API management files are located as follows:

* **API Configuration File:** `MovieCatalog/Data/Network/Constants/APIConfig.swift`
  * *Purpose:* Manages the central API endpoints, base URLs, and network constants.
* **Xcode Configuration Settings:** `MovieCatalog/Resources/Config.xcconfig`
  * *Purpose:* Keeps build settings, environment variables, and API keys separated from the source code.
